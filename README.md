# Ignite — project website

Fictional brand for the Digital Marketing course project. Static HTML, no build step.

## Host on GitHub Pages

1. Create a repo (e.g. `ignite-site`)
2. Push everything in this folder to the repo root (`index.html` must sit at root)
3. Repo Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)` → Save
4. Live at `https://<username>.github.io/ignite-site/`

Note: if hosted at a subpath, update the absolute URLs in `sitemap.xml` / `robots.txt` to the real github.io domain.
